2. **Recover all confirmed-alive Cluster victims** — Tier-1 access shoring + extraction for Clusters V-1 (Sector A Floor 8), V-2 (Sector A Floor 6), V-5/V-6 (Sector B post-gas-iso), V-14/V-15 (Sector C vehicle pocket), V-35/V-36 (SubD-1) by E+14:00.

4. **Achieve 110 cumulative shore points created** — Pace SP creation to budget; emphasize Tier-1 victim-driven SPs.
5. **Integrate arriving resources** — TF-State (E+5:00 main body) + TF-Fed-Alpha (E+12:00 advance, E+14:00 main body) integrated into Type II ICS structure by their respective arrival; Unified Command with LE established E+6:00.

## Block 4 — Operational Period Command Emphasis
- **Force protection:** Cantilever Floor 11 + Pile Sector D suspended fragments — no entry until shored or rigging-supported.
- **Heat / hydration:** Day-shift temperatures rising 78 → 89 → 82 °F; LSC manages rehab cycle on 60-min rotation.
