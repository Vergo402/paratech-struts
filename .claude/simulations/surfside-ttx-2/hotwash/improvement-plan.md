## Methodology notes

- Source synthesis: every tag from every AAR has been mapped to ≥1 row. Multi-source rows (≥2 citations) tagged with all sources. The Add-SP modal Save Changes bug (IP-007) had the highest source count (7 AAR files cite it) reflecting the 4-OP-running regression status.
- Coverage tagging: `covered` = explicitly in MASTER-PLAN Release 3 with a phase number (e.g., 3C.5 role history, 3C.7 group→assignedResource rename); `partial` = MASTER-PLAN scopes but doesn't fully solve (e.g., 3A Auth has anonymous auth but no per-agency scope); `gap` = within v4.0.0 scope but not currently planned; `new-idea` = beyond current v4.0.0 plan, candidate for v4.x backlog.
- AAR Question tagging: Q2-actual rows describe what was observed to happen; Q3-sustain rows capture what worked and should not regress; Q4-improve rows are recommendations from the AAR Q4 section.
- The 30-entry `ui_friction_logged_by_participants` array in `conductor-state.json` is the primary participant-side source; every entry maps to one or more IP-# rows.
