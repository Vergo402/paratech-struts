FieldShore · Operations — three views, two devices

The incident, read three ways — Division (by floor), Board (by status), List (flat & sortable) — each built for phone (on the floor) and iPad (the command post). A view switcher sits on every screen, so anyone can read the operation whichever way the moment calls for. Same data throughout: one operation, nine shore points, standing verify on SP-3.

Division — by floor

The building section. Phone stacks floors top-to-bottom for the thumb; iPad spreads the same section wide with a command rail — verify alert, op rollup, flagged point.

Board — by status

Every point in its status lane. Phone runs lanes as rows behind a narrow pinned count gutter; iPad opens them into six full Kanban columns. The floor's daily driver.

List — flat & sortable

The fastest scan. Phone groups rows by status under thin headers; iPad breaks the same groups into individual cards — point, location, type, measure, crew. Sort by any axis.
