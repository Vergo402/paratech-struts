# v4 Mess-Map — Stage 0 baseline (2026-07-05)

Code-side audit: 6 parallel agents over inventory / settings / operations / quickfind / command / shell+primitives, cross-checked against live screenshots in `baseline/` (phone 390×844 + desktop 1280×800, Dark). Feeds the elevation program (epic #430).

## Cross-screen themes (synthesis)

1. **Gold-budget blowout is the #1 source of the "noisy" feel.** Doctrine says one gold accent; practice shows 5–8 simultaneous gold elements per screen (see per-area gold counts below). The elevation language enforces a budget: 1 gold primary action per view + nav active state; selection moves to ink/weight, secondary actions demote to neutral.
2. **Double-title pattern** (app-bar title + identical in-screen h1) on Inventory and Settings; Quick Find's app-bar shows the brand instead of the tab name — three different header behaviors across five tabs.
3. **Content is flatter than chrome.** Data rows are bare hairline rows on the page background while buttons/tabs above them get surfaces — the actual content out-ranked by controls. Card anatomy v2 inverts this.
4. **Numbers carry no hierarchy.** Availability counts, measurements, and stats render at caption sizes with numerator/denominator at equal weight. Numerals-as-heroes fixes the screen's primary datum everywhere.
5. **Placeholder-grade fragments shipped**: floating nav pull-tab "debris", bare-text empty states with no action, unlabeled counts, v3 color jargon in user copy, broken uptime formatter.
6. **Token discipline drift**: raw `1px solid` (breaks Sunlight's 2px strokes), hardcoded px/rem off the ramp, magic widths — concentrated in newer CSS blocks.
