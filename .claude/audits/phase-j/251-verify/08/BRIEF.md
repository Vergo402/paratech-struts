# Criteria brief 08 — Joining a department by invite code

- **Spec:** `docs/v4-design/09-workflows/08-joining-by-invite-code.md` (Phase G issue #232, epic #135). Source IA spec: `docs/v4-design/08-information-architecture/72-invite-code.md`.
- **Build:** `src/ui/dept/JoinDepartmentScreen.tsx` (route `/join-department`), service `src/data/dept/departmentService.ts` (`joinByCode`), offline banner `src/app/shell/SyncBanner.tsx`.
- **Workflow in plain words:** a signed-in firefighter with no department opens the Join screen, scans the department QR or types/pastes the code (format `XXXX-XXXX`), taps Join department, sees a "Joined <dept>" confirmation with a Default role badge, taps Continue, and lands in the app as a Default-role member. Bad codes give a calm inline message. Offline, the join is held and finishes on reconnect. Continue as guest leaves without joining. The Admin sees the new member in User Manager on next sync; nobody is pushed a notification.

## Setup (QA agent builds this first, through the app's UI)

Harness per `HARNESS.md` (emulators + `dev:emu` :5200). Phone viewport 390x844.

1. **Device A (admin), `http://localhost:5200`:** `/auth` → Create Account (display name, email `qa251-08-a@example.test`, password) → lands on `/create-department` → create a department (name e.g. "QA08 Fire Rescue"). Read its **invite code** (format `XXXX-XXXX`, ambiguous glyphs excluded) from Settings → Department (`/settings/department`, shows QR + code + Copy) or from User Manager (`/users`, "Invite code" block with **Regenerate**). Write the code down.
2. **Device B (joiner), `http://127.0.0.1:5200`** (separate origin, clean storage): `/auth` → Create Account (display name, e.g. `qa251-08-b@example.test`). With no department, the app routes to `/create-department`; the gate screen on a dept tab (e.g. `/operations`) reads "Set up your department" with buttons **Create department**, **Join an existing department**, **Sign out**.
3. **Second code for negative controls:** on Device A, in `/users` tap **Regenerate** (confirm) to kill the first code. Keep the first code as the "dead code". Use the regenerated code for the happy path. (Order so the happy path is run before or with the new code.)
4. Optional Device C (clean origin) for a guest/no-account probe: `/join-department` while signed out.

Routes: `/join-department` (pre-shell, no tab bar), `/auth`, `/create-department`, `/settings/department`, `/users`, `/operations`.

## Risks for the QA agent

- **QR scanning cannot be driven for real** in a headless/emulated browser: no camera feed. Judge only that the sheet opens, copy is right, denial is calm, and Close works. A scan result would call `submit` with the decoded text; you may exercise the same path by typing.
- **Spec copy vs build copy differ in small ways** (Scan QR vs Scan QR code; "Enter it by hand" label; Joined card vs Sheet with Continue button). These are SPEC-DRIFT, not FAIL, unless meaning is lost.
- **"Already used" and clock-based "expired" are not states** (08-S1, 08-S3). A regenerated code shows the "expired" copy; do not fail it.
- **Continue as guest and Back go to `/operations`**, which for a signed-in no-department user then shows the "Set up your department" gate. That is correct, not a wall; the guest still has Quick Find.
- **Joining reloads the page** into the department bucket (`reloadIntoActiveBucket`) on Continue. Screenshots taken right after may show a blank reload frame; wait for load.
- **Use `127.0.0.1:5200` for the joiner**; stale `localhost:5200` profile state caused false results earlier (LEDGER, #466). Clean the origin first.
- **Invite lookup has no timeout** (LEDGER known follow-up): on a weak/blocked connection Join may sit on "Joining…". Known, not a new finding unless it hangs online.
- **`joinByCode` already-in-a-department guard**: the only guard is same-department short-circuit (08-19). Joining a *different* department while in one is a known gap noted in the LEDGER, outside this spec; record if seen but do not chase.
- **Offline test needs both** `goOffline` and the `offline` event, or the join resolves via the cached socket. A join queued before the code was ever resolved shows "your department" in the banner (name unknown).
- The joined sheet's `Admin`/`Default` badge reflects the service's returned role; for a first-time joiner it must say Default.
