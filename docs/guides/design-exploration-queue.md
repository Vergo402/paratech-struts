# Design Exploration Queue

Open design ideas from the FieldShore v4 board (epic #383), generated by
`/ship-design-ideas` on 2026-07-02. Build a mockup for each using the real
FieldShore components in this project. Each item links its board issue —
when an idea is resolved, its issue is closed and it leaves this queue.

## #384 — Plate/connector pickers — real photo thumbnails
- **What:** replace the letter/initial swatches in the plate & connector pickers with real photo thumbnails of each base plate / connector
- **Where:** picker/VisualGridPicker, picker/PlateSwatch (the connector + base-plate pickers)
- **Why:** letter swatches (e.g. "MB" for Multi-Base) are abstract — field users recognize the physical part by sight, and a photo is faster and less error-prone under stress. Carried from the Phase-H gaps register (#8), untracked until now.
- Issue: https://github.com/Vergo402/paratech-struts/issues/384

## #389 — Cutting Station empty state
- **What:** show a calm empty state ("No cuts queued") instead of rendering nothing when the station has no work
- **Where:** operations/CuttingStation
- **Why:** an empty queue currently renders blank (the component returns null); a designed empty state confirms "nothing to cut" and matches EmptyState doctrine. Surfaced while authoring the design-sync preview.
- Issue: https://github.com/Vergo402/paratech-struts/issues/389

## #390 — Individual saw stations — scoped view per assigned station
- **What:** Each saw station (A, B, +N) gets its own screen showing only that station's current cut + the full pending list
- **Where:** operations/CuttingStation
- **Why:** Officers assigned to a specific saw station should focus on their queue, not the full operation queue. Reduces cognitive load and field distractions under pressure (gloves, sun, stress).
- Issue: https://github.com/Vergo402/paratech-struts/issues/390

## #391 — Collapsible nav bar
- **What:** Make the primary nav bar collapsible so it can be hidden to reclaim screen space.
- **Where:** App shell — bottom nav (phone) / side nav (desktop).
- **Why:** Dense field screens (Operations board, Command, Cutting Station) need maximum vertical room; a fixed nav bar permanently eats space the user may not need while heads-down in a workflow.
- Issue: https://github.com/Vergo402/paratech-struts/issues/391

## #392 — Change Command nav icon to simple hierarchy tree
- **What:** Replace the Command tab's nav icon with a simple hierarchy / org-tree glyph.
- **Where:** App shell — primary nav, Command tab icon.
- **Why:** A hierarchy-tree icon reads as ICS command structure at a glance; the current icon doesn't signal "org chart / command" intuitively.
- Issue: https://github.com/Vergo402/paratech-struts/issues/392

## #409 — Sort in-stock connectors to top of deduction picker
- **What:** In the connector/base-plate picker used for strut deductions, sort items currently in inventory to the top; list items not in inventory below, slightly greyed out but still selectable.
- **Where:** Connector / base-plate deduction picker (Quick Find deduction + Operations deploy flows)
- **Why:** In the field the connector actually on the truck is what matters — surfacing in-stock options first speeds selection and steers away from picking one you don't have on hand.
- Issue: https://github.com/Vergo402/paratech-struts/issues/409
